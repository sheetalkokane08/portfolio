# SHEETAL.EXE — portfolio update

This version includes Sheetal's portrait embedded directly in `index.html`, so the Player Profile photo still appears even if the separate image asset is not uploaded. The `assets/sheetal-portrait.jpg` copy is also included for future editing.

## Publish with GitHub Pages
1. Extract this ZIP.
2. Open the extracted `sheetal-pixelquest-ready` folder.
3. Upload **the contents of this folder** (not the folder itself) to the root of your GitHub Pages repository.
4. Make sure `index.html`, `resume.pdf`, and `assets/` are at the repository root.
5. Commit the changes and wait for GitHub Pages to redeploy.
